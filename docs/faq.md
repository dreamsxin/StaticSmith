# 常见问题

**标题、日期、标签一定要手写 TOML 吗？**

不用。编辑器标题栏的「属性」面板把 front matter 的常用字段做成了表单：
标题、日期、描述、标签（逗号分隔，输入时给出全站已用过的标签候选）、草稿开关。
改完仍需保存——表单只改编辑器里的源文，不偷偷写盘。

换算在 Rust 侧做（`crates/staticsmith-core/src/frontmatter.rs`，用 `toml_edit` 保序改写），
所以正文、注释、你自己加的键与书写顺序都不会被洗掉。字段清空等于删键，
`draft` 取消勾选也直接删掉，而不是留一行 `draft = false`。
源文仍然是唯一真相：手改 `+++` 里的内容后表单会跟着变；写坏了表单会提示不可用，
修好即恢复，不会出现「表单值」和「源文」两份互相覆盖。

**有哪些快捷键？**


- `Ctrl/Cmd+S` 保存当前内容
- `Ctrl/Cmd+B` / `Ctrl+I` 加粗 / 斜体，`Ctrl+K` 插入链接（作用于选区）
- `Ctrl/Cmd+Enter` 增量生成，`Ctrl+Shift+Enter` 生成全站

内容页的三栏宽度可以拖动分隔条调整，会记在本机。

**切换文章时改动会丢吗？**

不会。有未保存改动时切换会被拦下来，让你选「保存并切换 / 放弃改动 / 留在本页」。
编辑器标题栏与左侧列表都会显示 `●` 标记未保存状态，状态栏也有提示。

**手动修改 `templates/` 下的源文件，界面能识别吗？**

能。后端有文件监听服务（`watch.rs`），检测到变更后发出 `project://changed` 事件，
界面顶部出现提示。点击「刷新组件树」重新加载模板并重算影响范围。
监听不会自动覆盖你正在编辑器里编辑的内容。

界面自己的保存不会触发这条提示：写盘前会登记路径，监听事件到达时对消掉
（`src-tauri/src/state.rs` 的 `SelfWrites`），否则每次保存都要看一遍「检测到外部修改」。

**改完内容，为什么服务器预览还是旧的？**

产物目录要重新生成才会变，内存预览则是即时的——两者的差别就在这里。
在预览面板勾上「保存即生成」，保存后自动跑一次增量生成，iframe 也会跟着重载；
这个开关记在本机，默认关闭（大站点的一次增量也要秒级，不替你决定）。
CLI 侧对应的是 `staticsmith serve`，它默认监听源目录自动重建。


**索引文件损坏或误删了怎么办？**

直接删除 `.staticsmith/index.db` 即可。索引只是缓存，下一次构建查不到任何页面记录，
会全部重建，等价于全量生成。

**为什么修改了模板，增量生成却没有覆盖某个页面？**

两种可能：

1. 模板用了动态 include（`{% include page.template %}`），无法静态分析依赖。
   这类情况需要手动「生成全站」
2. 页面用 front matter 的 `template` 指定了别的模板，而那个模板不在变更闭包内

**统一模板支持多语言（i18n）吗？**

`site.language` 会传给模板，可以据此切换文案。但内置的 i18n 宏库与多语言构建
（每种语言一套输出）尚未实现，目前需要自己在模板里做条件判断，或建多个站点项目。

**Tauri 应用如何保证本地数据安全？**

FTP 密码与 Git Token 通过 `keyring` 写入操作系统凭据管理器
（Windows Credential Manager / macOS Keychain / Linux Secret Service）。
`staticsmith.toml` 里只有环境变量名与私钥路径，配置文件泄露不会暴露密钥。
发布层的 `Credentials` 类型手写了 `Debug`，日志里不会出现密钥内容。

**我的网站有复杂的 JS 交互或特殊字体，会被破坏吗？**

不会。把外部资源引用放进 `layouts/base.html` 的 `{% block head %}` 或
`{% block scripts %}`，生成时原样保留。开启 `minify` 时压缩只折叠标签间空白，
`pre` / `code` / `script` / `style` / `textarea` 内部完全不动。

**分页地址能自定义吗？**

目前固定为 `<栏目>/page/N/`（第 1 页写在栏目根）。这个规则在
`build.rs::Pagination::output_path` 中实现，需要改可以在那里调整，
模板侧无需变动，因为地址由后端注入。

**可以只用生成引擎、不要桌面界面吗？**

可以。`staticsmith-core` 不依赖 Tauri 与任何 GUI 能力：

```rust
use staticsmith_core::{build::BuildMode, Builder};

let mut builder = Builder::open("./my-site")?;
let report = builder.build(BuildMode::Incremental)?;
```

**标签页是怎么生成的？**

front matter 里写 `tags = ["模板", "增量构建"]`，构建时自动聚合出 `/tags/`（总览，
按篇数排序）与 `/tags/<标签>/`（单标签，沿用 `build.page_size` 分页），
文章页的标签也会变成指向标签页的链接。中文标签在 URL 里保留原字，不转拼音。

标签页不进增量索引：它们是全站 tags 的聚合视图，任何一篇文章改标签都会影响，
所以每次构建整体重算——数量通常只有几十，成本可忽略。

关掉 `[taxonomy] enabled` 后既不生成标签页，也不会在文章页渲染标签链接
（否则会留下指向不存在页面的死链）。

**界面里在哪看标签页？**

标签页、分页页没有对应的源文件，左侧内容树按源文件组织，所以它们不在文章列表里。
两个入口：

- 内容树底部的「站点页面（生成）」分组
- 「生成」标签页的「产物清单」，按类型分组列出全部产物，含 sitemap、订阅源与静态资源

点击任一项会在预览面板打开它。这类页面不能走内存预览（没有源文件可渲染），
所以点击时会自动拉起本地预览服务器；旁边的 `↗` 用系统浏览器打开。
清单在打开站点与每次生成后自动刷新，也可以手动点「刷新」。


**怎么删除一篇内容？**

在左侧列表里把鼠标移到条目上会出现 `×`，点一次变成「确认删除 / 取消」，再点才真删。
删除只动源文件：已生成的 HTML 留在产物目录里，下一次生成时按 `orphaned_pages` 清理，
所以删完状态栏的待生成数会变化，生成面板也会列出「将清理…」。
删掉的是正在编辑的那篇时，编辑器会一并清空。

**草稿会被发布出去吗？**


不会。`draft = true` 的页面既不进产物，也不出现在列表页的 `items` 与全站 `pages` 里。

**粘贴进来的图片存到哪了？能改吗？**

默认存到 `static/images/<哈希前两位>/<哈希>.<扩展名>`，页面里引用 `/images/...`。
存放位置由 `[build] static_dir` 与 `[assets] dir` 决定，命名方式、哈希长度、是否分片、
URL 前缀都可以在「设置」里改。完整说明见 [媒体资源与目录结构](assets.md)。

**为什么预览里的图片显示不出来？**

内存预览会把本地样式表与图片就地嵌进 HTML（`srcdoc` 沙箱没有文件访问权限，只能这么办），
所以大多数情况下现在看得到。仍然看不到通常是三种：单个文件超过 2 MB、一页累计超过 8 MB
（预算内的先嵌，超出的原样留着），或者那是脚本／外链资源。预览栏底部会写明还有几处没嵌进来。
要与线上完全一致，点「启动本地服务器」：它起一个只监听 127.0.0.1 的静态服务器指向产物目录
（需要先「生成」一次）。CLI 里对应 `staticsmith serve`。

**同一张图片粘贴多次会占多份空间吗？**

不会。文件名就是内容哈希，第二次粘贴会命中已有文件并直接复用，返回结果里 `deduplicated`
为 `true`。删掉文章不会自动删掉它引用过的图片——那样太容易删掉别处还在用的文件；
改成显式体检：「体检」标签页的「媒体资源」卡片列出没人引用的文件与引用了却不存在的地址，
勾选后二次确认才删。判定会把模板与主题里的引用算进去，`logo.png` 不会被误判成垃圾。


**已经上传过的图片怎么再插一次？**

编辑器工具条的「媒体库」列出全部已登记资源，点一下就把地址插到光标处。
不用再去磁盘里找原图，也不用重新上传一遍。
缩略图要走 HTTP（WebView 读不到磁盘文件），所以启动本地预览服务器并生成一次之后才显示，
在那之前列出的是文件名。

**怎么知道 Token / 密码有没有存进系统凭据管理器？**

发布面板的「凭证」区会显示「已存储 / 未存储」，条目名跟着发布配置变化时自动重查。
已存储时可以直接覆盖，也可以点「删除凭证」移除。
凭证本身不会回读到界面上——只查在不在。
